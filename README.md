# Michal's Stationeers mods

This repository hosts Stationeers mods made by Michal Řeháček.
The following mods are available:
- [Image Screens](ImageScreens/README.md): screens showing images or slideshows from a web server


## DLLs inside Assets/Assemblies

The DLL files that need to be present inside Assets/Assemblies are not part
of the repository, because they are not redistributable.
The repository has a script LinkDLLs.sh.
Run it, with an argument pointing to the Stationeers install directory,
and it will copy the DLLs there from your local game folder.
You have to have BepInEx and LaunchPadBooster installed already.
